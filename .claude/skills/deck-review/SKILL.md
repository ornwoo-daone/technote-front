# 새로 쓴 덱 검증

변환 덱은 «원본과 같은가»를 보면 되지만, 직접 쓴 덱은 대조할 원본이 없다.
그래서 **틀려도 아무도 모른다.** 아래 5가지를 순서대로 확인한다.

## 1. 사실 근거 — 지어내지 않았는가

가장 중요하고, 자동화가 안 되는 부분이다.

- **코드를 인용했다면 그 파일을 다시 열어 줄번호를 확인한다.** 기억으로 쓰지 않는다.
  파일이 수정되면 줄번호는 조용히 어긋난다.
- 인용한 코드 조각이 실제 소스와 **문자 단위로 같은지** 확인한다. 요약·의역 금지.
- 외부 사실(표준 연도, 알고리즘 이름, 약자 풀이)은 확신이 없으면 **덱에서 뺀다.**
  "아마 그럴 것"을 단정문으로 쓰지 않는다.
- 확인 못 한 항목은 지우거나 `<Muted>미확인 — 근거 못 찾음</Muted>` 으로 표시한다.

고객 대응·장애 분석 덱은 특히 엄격하게. **틀린 근거는 없느니만 못하다.**

## 2. 렌더 결과 — 실제로 그렇게 나오는가

빌드가 통과해도 화면이 틀릴 수 있다. 컴파일 결과를 직접 센다.

```bash
# dev 서버가 떠 있어야 한다 (http://localhost:5173)
curl -s "http://localhost:5173/src/entities/docs/content/<cat>/<slug>.mdx" \
  | grep -oE "_components\.(table|pre)" | sort | uniq -c
```

- **표를 썼는데 `_components.table` 이 0이면 표가 파이프 문자로 렌더된다.**
  (`remark-gfm` 누락으로 덱 10개가 이 상태였던 적이 있다)
- 코드 펜스 개수와 `_components.pre` 개수가 맞는지 확인한다.
- 슬라이드 수: `grep -c "<Slide" <파일>` — 6~12장이 적정. 넘으면 주제를 쪼갠다.
  (레퍼런스 성격의 덱은 예외로 두되, 왜 예외인지 보고에 밝힌다)

## 3. MDX 함정

빌드 에러로 드러나는 것과, 조용히 틀리는 것이 있다.

**빌드가 잡아주는 것** — 고치면 끝
- 컴포넌트 안에 빈 줄: `<Note>내용\n\n다른 문단</Note>` → 여는/닫는 태그를 각자 자기 줄로

**조용히 틀리는 것** — 직접 확인해야 함
- 코드 펜스 **안**에서 `\{` 처럼 이스케이프 → 백슬래시가 그대로 화면에 보인다.
  펜스 안은 이스케이프가 필요 없다. 펜스 **밖** 본문에서만 `\{` `\}` 를 쓴다.
- 마크다운 표를 `<div className="tscroll">` 로 감싸기 → `mdxComponents.table` 이 이미 감싼다. 중복이다.
  직접 쓴 JSX `<table>` 만 수동으로 감싼다.
- SVG 속성을 camelCase 로 안 바꿈 (`stroke-width` → `strokeWidth`)
- 본문의 `<` 가 태그가 아니면 `&lt;` 또는 백틱

## 4. 배치 — registry 항목이 맞는가

```bash
grep -n "slug: '<slug>'" -A5 src/entities/docs/registry.ts
```

- `cat` 이 내용과 맞는가. **계기가 아니라 내용으로 분류한다.**
  (고객 문의에서 시작했어도 내용이 우리 코드 설명이면 그 제품 카테고리)
- `session` 이 그 카테고리의 탭에 실제로 있는 키인가 → `npm run test` 가 잡는다
- `k`(검색 키워드)에 **한글·영문을 같이** 넣었는가. 검색이 단순 부분일치라 표기가 다르면 안 걸린다
- `at` 이 오늘 날짜인가
- 학습 노트에 `deploy` 를 넣지 않았는가 (DB 실무 노트 전용)

## 5. 상호 참조 — 다른 덱을 가리키는 문구

**덱을 옮기면 여기가 조용히 틀어진다.** 실제로 두 번 발생했다.

- 다른 덱을 «제목» 으로 가리켰다면, 그 덱의 **현재 카테고리 이름**이 맞는지 확인한다
  (`INFRA · «TLS 기초»` 라고 써놨는데 그 덱이 «보안» 으로 옮겨간 경우)
- `npm run test` 의 `deck-crossref.test.ts` 가 카테고리 이름 불일치를 잡는다.
  제목 자체가 바뀐 경우도 함께 걸린다.

## 마무리

```bash
npm run build     # typecheck → test → webpack
```

통과 못 했으면 **통과 못 했다고 출력과 함께 보고한다.** 요약해서 넘기지 않는다.
