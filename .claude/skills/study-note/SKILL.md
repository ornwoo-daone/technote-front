# 학습 노트 작성

DB 실무 노트(`work`/`concept`/`verify`)와 성격이 다르다. 실무 노트는 **검증된 사실 기록**이고
학습 노트는 **이해한 것의 정리**다. 그래서 구조를 다르게 잡는다.

## 세션 고르기

학습 카테고리의 탭은 `STUDY_SESSIONS` 네 개다. 문서 하나에 하나만 고른다.

| session | 쓸 때 | 예 |
|---|---|---|
| `basic` | 개념·문법의 기본기 | "제네릭이란", "포인터와 배열" |
| `practice` | 직접 만들어 본 것 | "이 사이트를 TS 로 전환하며 겪은 것" |
| `deep` | 내부 동작·원리 | "G1 GC 의 리전 관리", "이벤트 루프의 마이크로태스크" |
| `issue` | 막혔다가 푼 것 | "as const 로 export 하면 옵셔널 필드 접근이 막히는 이유" |

애매하면 `basic`. 나중에 한 줄 고치면 된다.

## 덱 구조

한 덱은 **6~12 슬라이드**. 넘어가면 주제를 쪼갠다.

```mdx
<Slide kick="React · 기초">
<h1>훅의 규칙<br/>왜 조건문 안에서 못 쓰나</h1>
<Lead>훅은 **호출 순서**로 상태를 찾는다. 이게 모든 규칙의 이유다.</Lead>
</Slide>

<Slide kick="문제">
## 이렇게 쓰면 깨진다
```js
if (cond) useState(0);   // 렌더마다 훅 개수가 달라진다
```
<Warn>React 는 훅을 이름이 아니라 **순서**로 식별한다.</Warn>
</Slide>

<Slide kick="원리">
## 왜 그런가
<Flow steps={[
  {t:'렌더 시작', d:'훅 인덱스 0 으로 초기화'},
  {t:'useState 호출', d:'인덱스 0 슬롯에서 상태를 꺼냄', accent:true},
  {t:'다음 훅', d:'인덱스 1 …'},
]} />
</Slide>
```

컴포넌트 사용법·MDX 문법 함정은 `.claude/rules/mdx-authoring.md` 의 대응표를 본다.

## 좋은 학습 노트의 조건

1. **첫 슬라이드에서 결론을 말한다.** "왜 그런가"를 리드 문장에 먼저 박는다.
   뜸 들이는 구성은 나중에 다시 볼 때 쓸모가 없다.
2. **틀렸던 이해를 같이 적는다.** `<Warn>` 으로 "이렇게 알고 있었는데 아니었다"를 남기면
   같은 실수를 반복하지 않는다. 학습 노트에서 제일 값어치 있는 부분이다.
3. **코드는 최소 재현으로.** 실제 프로젝트 코드를 통째로 붙이지 않는다.
4. **확인 안 된 건 확인 안 됐다고 쓴다.** 추측을 사실처럼 적으면 노트가 오염된다.
   `<Muted>미확인 — 문서 근거 못 찾음</Muted>` 처럼 표시한다.
5. **이 repo 와 연결되면 링크한다.** TypeScript·React·CSS 는 이 프로젝트에 실물이 있다.
   "여기서 실제로 이렇게 썼다"가 있으면 훨씬 오래 남는다.

## 등록

`src/entities/docs/registry.ts` 의 `DOCS` **맨 앞**에 추가한다.

```ts
{ cat: 'react', slug: 'hook-rules', session: 'basic', at: '2026-08-12',
  t: '훅의 규칙 · 왜 조건문 안에서 못 쓰나',
  d: '훅은 호출 순서로 상태를 찾는다',
  k: 'react hook 훅 규칙 순서 조건문 usestate 인덱스 슬롯',
  load: () => import('./content/react/hook-rules.mdx') },
```

- `k`(검색 키워드)에 **한글·영문을 같이** 넣는다. 검색이 단순 부분일치라 표기가 다르면 안 걸린다.
- `deploy` 필드는 학습 노트에 쓰지 않는다 (배포 버전 추적용, DB 실무 노트 전용).
- `at` 은 오늘 날짜. 알림·정렬이 이 값을 쓴다.

## 하지 말 것

- 내용을 모르면서 그럴듯하게 채우기. 뼈대만 두고 **비워서 넘긴다.**
- 한 덱에 여러 주제 몰아넣기. 12 슬라이드가 넘으면 쪼갠다.
- 공식 문서를 그대로 옮겨 적기. 이해한 방식으로 다시 쓴 게 아니면 노트가 아니다.
